# trevornoon.com

Personal website for Trevor Noon — a Bento-style portfolio built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step.

## Editing content

Everything on the page is driven by **`js/data.js`**. To add or change a card:

- **Experience / Links** — add an entry with a `theme` (`bg` color or gradient + `ink: "light" | "dark"`) and a transparent logo PNG in `images/logos/`. The card itself is generated by CSS — no image editing needed.
- **Projects / Interests** — add an object with `image` and optionally `title`, `subtitle`, `href`. Each project links to its own page in `projects/<slug>/index.html` (a one-pager for builds, a reader view for co-authored guides), styled by `projects/project.css`.
- Set `hidden: true` on an entry to keep it without showing it, or `confidential: true` to veil it.

## Previewing

Open `index.html` in a browser, or run `python3 -m http.server` and visit `http://localhost:8000`.

## Repo layout

| Path | What it is |
| --- | --- |
| `index.html` | Page shell, meta/SEO, section containers |
| `styles.css` | Design system (CSS custom properties, light + dark) |
| `js/data.js` | All site content — edit this |
| `js/site.js` | Renders content and wires up interactions |
| `projects/` | One page per project, plus the shared `project.css` |
| `images/logos/` | Transparent logo marks used by the generated cards |
| `scripts/extract-logos.py` | One-time tool that pulled logo marks out of the old Figma tiles |
| `portal*.html`, `api/` | Separate password-gated portal (Vercel) — independent of the main site |

## Performance notes

Keep photos ≤1000px on the long edge and compressed (progressive JPEG ~q80). Card artwork is code-generated, so there are no heavy tile images to maintain.
