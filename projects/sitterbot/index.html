SitterBot

An AI assistant for babysitters. Parents tell it about their kids once, and sitters can ask it anything, any time.

The problem

Every handoff to a sitter is a brain dump: bedtime, allergies, the routine, which stuffed animal absolutely has to be in the bed. It lives in a note on the fridge or a long text thread, it's out of date the moment you write it, and nobody wants to text a parent in the middle of bedtime to ask.

Why I built it

I built it as a parent. The idea was to make the handoff something you do once, and do well, and then let the sitter ask questions in plain English instead of digging through texts.

The fridge note, but it answers back.

What it does

  • An AI-guided setup walks parents through a profile for each child, so the important details actually get captured.
  • Parents share a profile with any sitter by email, set an end date, and revoke access whenever they want.
  • Sitters chat with a bot that answers only from what the parents shared, and says so when it doesn't know.
  • Under the hood, it's retrieval over each child's profile with Supabase and pgvector, and OpenAI for the chat.

What it's changed for me

SitterBot is where I learned the way I still build: write the PRD first, break it into tasks, and let an agent work through them while I review each one. Back then it was Cursor and a task list. Forage and Form came from the same habit, with better tools.

It's still a prototype with a waitlist. It answered the question I had, and it made every build after it better.
